# Data

The microdata for this project are not stored in this repository. GESIS terms of use prohibit redistribution of Eurobarometer microdata.

## How to obtain the dataset

1. Create a free account at [gesis.org](https://www.gesis.org)
2. Sign in and open the study record: [DOI 10.4232/1.14471](https://doi.org/10.4232/1.14471)
3. Accept the usage terms
4. Download the microdata analysis file in SPSS format (`.sav`)
5. Place the file in this directory

Also download and read:

- The **basic bilingual questionnaire** — exact question wording for QB1 through QB11
- The **archive variable report** — variable names, value labels, and missing codes

## Note on version

The current release is an archive pre-release. Variable and value label completeness may be lower than a final archive edition. Always verify variable codes against the downloaded variable report rather than relying on the online variable search.
